# KOSMOS

Public homepage and roadmap of KOSMOS, the Kerbal Organization for Socialist Missions in Outer Space: a Kerbal Space Program career in the Ciro system.

- `index.html`: homepage (Pechka 1 on Vesta, vehicles, next missions)
- `roadmap.html`: the program roadmap, exported from the Director's working copy on 8 November 2026

Static site, no build step. Served with GitHub Pages from the `main` branch root.
